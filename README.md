# Flappy Bird Python Game

A 2D arcade game recreation of Flappy Bird built in Python using Zelle Graphics and Pygame.

## Features
- **Real-Time Game Loop:** Custom gravity acceleration and physics calculations.
- **Bounding-Box Collision Detection:** Dynamic hitboxes for obstacle interaction.
- **Event-Driven Audio:** Integrated `Pygame.mixer` for non-blocking music and sound effects.
- **Interactive UI:** Custom start menu, instructions overlay, score tracking, and game-over states.

## How to Run
Install dependencies:
```bash
pip install pygame
```
Run the main script:
```bash
python flappy_bird.py
```
